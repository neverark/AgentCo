# AgentCo

An AI procurement workspace: choose services, control spending, and verify outcomes.

面向 OKX Dev Day 2026 的项目。AgentCo 根据用户的任务、预算和采购策略，选择 AI 服务、控制费用、验证交付，并积累服务的实际表现记录。

## 当前阶段

已初始化 Git，并整理产品范围与视觉演示方向。当前仓库只有准备文档，尚无可运行应用，也尚未连接钱包、调用付费服务或完成 OKX AI 集成。

## 首个场景

**Verified Token Risk Snapshot：有证据支持的代币风险快照。**

输入代币、链、采购预算与策略，展示服务比较、预算预留、执行、验证和最终报告。将演示数据、录制的真实结果与实时调用明确标识。
